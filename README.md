# Home HQ

A family home dashboard built with Next.js. Designed to run on a wall-mounted tablet or TV.

## Sections

- **Today** — clock, weather, family locations, next event countdown, per-person schedules
- **Calendar** — day/week/month view, color-coded by family member
- **Chores** — per-person task columns with time-of-day tabs and progress tracking
- **Shopping** — grocery list grouped by category and store
- **Home** — smart home controls: lights, blinds, thermostat, cameras, now playing
- **Agents** — AI service usage dashboard (Claude, Codex, Cursor, Gemini, Copilot)

## Stack

- Next.js 15 (App Router)
- Tailwind CSS v4
- TypeScript

## Dev

```bash
npm run dev
```
